# 模糊

一个图片越清晰，边缘就锋利，那么拉普拉斯方差通常更大，所以可以用一个阈值快速判断清晰度。

除此之外还可以使用 Sobel 等梯度方法，还可以训练 CNN 模型直接输出图像清晰度评分。拉普拉斯方差最简单高效

## 拉普拉斯方差

1. 拉普拉斯算子：负责找“边缘”
    - 图像处理中的二阶微分算子（求二阶导数）。
    - 物理意义：它对图像中像素灰度发生**剧烈变化的地方（即边缘、纹理、轮廓）**极度敏感。
        - 清晰图像：边缘锐利，像素明暗跳变大，经过拉普拉斯卷积后，边缘处会产生极大的正值和极大的负值。
        - 模糊图像：边缘被抹平（平滑过渡），像素变化平缓，经过拉普拉斯卷积后，所有响应值都接近 0。
2. 方差（Variance）：负责统计“响应的剧烈程度”
    - 方差衡量的是一组数据的离散程度（波动大小）。

常用的 3×3 拉普拉斯卷积核：
```
0  1  0
1 -4  1
0  1  0
```

### 原本清晰的大图缩放会影响吗

原图：黑 → 深灰 → 灰 → 浅灰 → 白
缩小：黑 ───────────────→ 白

### 具体步骤

1. 缩放：如果原图宽度 <= 512：不缩放，直接用原图如果原图宽度 > 512：等比例缩放到宽度 512
2. 转灰度图：彩色图会转成灰度，因为模糊判断主要看亮度边缘变化，不依赖颜色
3. 并行计算方差，小于阈值则为模糊，

# 相似检测

1. 传统哈希（MD5 / SHA）：

一张图片，只要修改其中 1 个像素的颜色，生成的 MD5 就会天翻地覆、完全不同。它用来验证“绝对一致性”，无法感知“长得像不像”。

2. 感知哈希（pHash / dHash / aHash）：

它会主动扔掉微观噪点和色彩细节，只提取图像的“宏观结构骨架”。如果两张图视觉上长得很像，生成的 64 位二进制指纹（如 11001010...）绝大部分位就会是一模一样的。

图片解码轻量，pHash、dHash可缓存。SIFT/ORB 局部特征匹配太重，深度学习提取图片 Embedding要占算力和存储

## 算法

1. 感知哈希

例如 aHash、dHash、pHash，通过生成视觉特征哈希并计算汉明距离判断相似度；
- aHash (Average Hash - 平均哈希)：极快，比较扁平，适合粗筛
- pHash (Perceptual Hash - 感知哈希)：它更关注图片整体视觉特征，速度一般，免疫一定程度的裁剪
- dHash (Difference Hash - 差异哈希)：更关注图片局部特征，对比的是相邻像素的“相对差值”，适合连拍照片

2. 汉明距离

汉明距离就是统计两个等长二进制串中，有多少个对应位置的 bit 是不相同的（异或操作 XOR 后数 1 的个数）。

例如两张图算出来的 8 位 Hash：
```
图 A：1 1 0 0 1 0 1 0
图 B：1 1 0 0 1 1 1 0（仅第 6 位不同）
汉明距离 = 1。
```

# 吞吐提升65.3%

启动扫描
  ├─ 全量：删除旧模糊/重复结果，读取该用户全部照片
  └─ 增量：取上一次成功任务的开始时间，只取之后新增或修改的照片
       （没有成功历史时退化为全量）

## 流程

1. 先决定开多少个消费者：min(CPU 核数, 8, 图片数量)
2. 再决定有上限的任务队列：jobs := make(chan blurJob, workers*2)
    - 图片可能有几千、几万张，放全部占内存
    - 太小，例如 workers：队列很快满，投递方经常阻塞。
3. 消费者并行干活：读取、解码图片，再计算清晰度/模糊度
4. 结果允许乱序回来，但最终会恢复顺序
    - 并发时，第 10 张图可能先于第 1 张算完。代码用 index 标记每张图片原本的位置，再存到 slots[r.index]。
5. 遍历slots，顺序添加到数据库里
6. 支持取消：函数不断检查 ctx.Err()
    - Worker 尚未开始处理某张图时，如果已取消，会标记任务为 skipped。
    - 主流程发现任务已取消或结果被标记跳过，就立即返回。
    - 被取消后，不再继续写后续 SQLite 记录。

## 效果

50张、100张、200张，旧版是一张一张算；新版是按 CPU 核数启 Worker Pool 并行计算模糊度；SQLite 仍保持单线程顺序写入，避免锁冲突，吞吐量从约 16.5 张/秒 提升到 27.3 张/秒，提升约 65.3%

## 数据集

人脸：
1. 人脸检测用了 WIDER val 全量 3226 张
2. 人脸识别/验证 LFW (Labeled Faces in the Wild) 人脸识别数据集 1000 pairs

检测指标是：
 - recall：真实目标有多少被找到了; 
 - precision：检测出来的人脸有多少是真的；
 - AP：综合结果
 - 通用性能：内存、cpu、峰值、耗时

模糊：
1. CUHK Blur Dataset 香港中文大学的数据集不太适合，因为是局部模糊的
2. 最后使用了CERTH Image Blur Dataset 希腊研究与技术中心

相似：
1. California-ND Dataset（加州近重复数据集） 701张
2. INRIA Holidays Dataset（假期照片数据集） 1491张

## 自己建立数据集该怎么做

1. 先明确任务和业务场景。比如是做人脸检测、人脸识别；室内还是室外、光照如何，是否有遮挡、模糊特殊情况。

2. 基于真实业务分布采集数据，可以来自用户授权数据、内部测试采集、公开数据集补充和合成增强。

3. 制定标注规范。检测任务标人脸框、关键点、遮挡、模糊、姿态等；

4. 最后划分`train`（训练集）、`val`（验证集）、`test`（测试集）。
