## Docker

Docker 项目主要封装 Docker Engine API，提供镜像、容器、网络和基础状态管理能力。比如查询本地镜像、删除镜像、创建容器、启停容器、查询容器状态、端口映射、挂载目录、环境变量配置等。

拉镜像是长耗时任务，所以接口先创建任务并返回 taskId，后端异步执行 docker pull，同时读取 Docker daemon 返回的 JSON stream。前端通过 SSE 订阅这个 taskId，后端把每一段进度事件转成 SSE event 推给前端。

SSE 比轮询实时性好、实现简单；如果要双向控制才考虑 WebSocket

## 数据库优化

### 媒体分页与时间轴查询优化

媒体分页和时间轴查询出现稳定慢查询。

通过 Explain query plan 分析发现，查询只命中了 deleted_at 索引，排序依赖 CASE 动态计算 filming_time 或 modified_at。

于是新增了 sort_time 字段，在媒体写入或更新时提前计算排序时间，查询阶段直接基于 sort_time 完成过滤和排序。

另一方面，分类查询先获取某个标签下所有 SHA，再通过 WHERE sha IN (...) 查询媒体数据，随着数据量增长，不仅需要在后端拼接超长 SQL，而且由于 IN 参数数量动态变化，数据库无法复用执行计划。因此改为 JOIN 查询，并补充关联索引。

最终分页和分类查询性能提升约 7 倍
