# 2.语言模型 配图规划

这篇文章的配图目标，是帮助读者理解语言模型能力如何一步步发展：先知道语言模型到底在做什么，再理解 RNN/LSTM 如何加入记忆，最后进入 Transformer 的并行注意力机制。

# 图 1：语言模型是干嘛的

**建议位置**：放在文章开头，位于“语言模型：从概率接龙到大模型”引言之后、N-gram 小节之前。

**图类型**：概率预测流程图。

**表达重点**：语言模型的基础任务，是根据已有上下文预测下一个最可能出现的 Token。它并不是直接“理解世界”，而是先计算候选 Token 的概率分布，再按概率生成输出。

**图中内容**：

```text
输入上下文
今天天气真 ____

语言模型计算候选概率
好：70%
冷：20%
桌子：0.01%

选择下一个 Token
输出：好
```

**推荐实现**：Mermaid。结构简单，适合直接嵌入文章，能作为全文的入口图。

# 图 2：RNN / LSTM 的串行记忆

**建议位置**：放在“RNN/LSTM：给模型加入连续记忆”小节中，解释 RNN 核心思想之后、介绍优缺点之前。

**图类型**：串行链路图 + LSTM 门控补充框。

**表达重点**：RNN 按顺序读取文本，并把隐藏状态一路传递；LSTM 在这条链路上加入细胞状态和门控机制，让重要信息更容易保留下来。

**图中内容**：

```text
RNN 串行读取
x1 -> RNN -> h1
x2 + h1 -> RNN -> h2
x3 + h2 -> RNN -> h3

LSTM 增强记忆
细胞状态 Cell State
遗忘门 Forget Gate
输入门 Input Gate
输出门 Output Gate
```

**推荐实现**：Mermaid。用流程图表达顺序依赖和隐藏状态传递即可，不需要复杂白板图。

# 图 3：Transformer 的 Self-Attention

**建议位置**：放在“Transformer：把全文摊开来看”小节中，介绍自注意力机制之后，或放在 Q/K/V 比喻段落附近。

**图类型**：Excalidraw 中心关系图 / 注意力示意图。

**表达重点**：Transformer 不再一个词一个词串行读取，而是让所有词同时进入模型；每个词都可以通过 Self-Attention 直接关注其他词。Q/K/V 机制决定“我想找什么”“谁匹配我”“匹配后给我什么信息”。

**图中内容**：

```text
句子：我 买 了 苹果 15 手机

苹果 Query：我在找科技产品相关信息
手机 Key：我是电子产品
匹配度高 -> 苹果关注手机
手机 Value 融入苹果表示
苹果 获得 科技品牌语义
```

**推荐实现**：Excalidraw。这个图是全文最关键的认知拐点，信息密度较高，用手绘白板图更容易让读者记住 Self-Attention 的工作方式。

# 优先级建议

1. **语言模型是干嘛的**：必加。它决定读者能否理解后文所有模型都在围绕“预测下一个 Token”演进。
2. **Transformer 的 Self-Attention**：强烈建议加。它是整篇文章最难、也最重要的概念。
3. **RNN / LSTM 的串行记忆**：建议加。它帮助读者理解为什么 Transformer 要摆脱串行结构。

# 实现策略

最终采用轻重结合的方式：

- 图 1“语言模型是干嘛的”：Mermaid
- 图 2“RNN / LSTM 的串行记忆”：Mermaid
- 图 3“Transformer 的 Self-Attention”：Excalidraw

这样可以把 Mermaid 用在结构清晰、维护成本低的解释图上，把 Excalidraw 留给最需要视觉化表达的注意力机制。
