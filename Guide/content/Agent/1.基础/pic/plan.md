# 1.基础 配图规划

这篇文章的配图目标，是帮助读者快速建立 Agent 的心智模型：它和普通 AI 有什么不同、内部如何循环、为什么会产生幻觉，以及工程上如何控制风险。

# 图 1：普通 AI vs Agent

**建议位置**：放在“智能体（Agent）与普通 AI 的本质区别”小节后。

**图类型**：左右对比图。

**表达重点**：普通 AI 主要是被动回答；Agent 会围绕目标主动规划、调用工具并推进任务。

**图中内容**：

```text
普通 AI
用户提问 -> AI 回答 -> 用户自己执行

Agent
用户给目标 -> Agent 规划 -> 调用工具 -> 执行动作 -> 反馈结果
```

**推荐实现**：Mermaid 优先。结构简单，适合直接嵌入文章，维护成本低。

# 图 2：Agent 运行循环

**建议位置**：放在“智能体的运行机制”小节后。

**图类型**：循环流程图。

**表达重点**：Agent 不是一次性问答，而是持续执行“观察 -> 思考 -> 行动 -> 反馈”的循环。

**图中内容**：

```text
感知 Perception
  -> 思考 Thought
  -> 规划 Planning
  -> 工具选择 Tool Selection
  -> 行动 Action
  -> 观察反馈 Observation
  -> 回到感知 Perception
```

**推荐实现**：Mermaid。作为文章核心流程图，直接嵌入 Markdown，后续维护成本最低。

# 图 3：Agent 为什么会产生幻觉

**建议位置**：放在“Agent 为什么会产生幻觉”小节开头或五个原因之后。

**图类型**：原因分解图 / 鱼骨图 / 中心辐射图。

**表达重点**：Agent 的幻觉不是单一原因，而是由模型底层、工具调用、记忆系统、多步规划和提示词交互共同造成。

**图中内容**：

```text
Agent 幻觉
├─ LLM 底层限制：概率生成不等于事实验证
├─ 工具使用偏差：参数幻觉、错误返回值误读
├─ 记忆偏差：RAG 脏数据、上下文过载
├─ 多步规划偏差：早期误差沿链路放大
└─ 谄媚与提示词敏感：迎合错误前提、被约束逼出答案
```

**推荐实现**：Excalidraw 优先。这个图信息密度较高，用手绘风格的中心辐射图会比 Mermaid 更直观，也更适合作为文章中的重点图。

# 图 4：Agent 风险控制四层防线

**建议位置**：放在“如何降低 Agent 的幻觉风险”小节后。

**图类型**：分层防线图。

**表达重点**：降低幻觉风险不是靠一句提示词，而是靠输入、过程、输出和权限四层工程约束。

**图中内容**：

```text
输入端
RAG 优化 / 数据质量 / 可追溯来源

过程端
自我检查 / 外部校验 / 数据库验证

输出端
Guardrails / 格式校验 / API 强校验

权限端
支付 / 删除 / 发布 / 外发消息需要人工确认
```

**推荐实现**：Mermaid。用分层流程图表达四层防线，清晰、轻量，适合直接放在文章中。

# 优先级建议

1. **Agent 运行循环**：必加，是理解 Agent 的核心。
2. **普通 AI vs Agent**：强烈建议加，帮助读者快速理解差异。
3. **Agent 为什么会产生幻觉**：建议加，能把抽象风险拆成可理解的原因图。
4. **风险控制四层防线**：适合增强文章的工程实践感。

# 实现策略

最终采用轻重结合的方式：

- 图 1“普通 AI vs Agent”：Mermaid
- 图 2“Agent 运行循环”：Mermaid
- 图 3“Agent 为什么会产生幻觉”：Excalidraw
- 图 4“Agent 风险控制四层防线”：Mermaid

这样可以把 Mermaid 用在结构清晰、维护频率较高的图上，把 Excalidraw 留给信息密度最高、最需要视觉记忆点的“幻觉原因图”。
