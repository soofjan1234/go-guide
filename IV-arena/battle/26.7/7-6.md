1. 自我介绍与在职状态
    1. 做一个自我介绍，说明你的 Go 后端经验、性能优化、跨端协同和 AI 工作流。
    2. 目前是离职还是在职。
    3. 为什么现在想看新的机会。
2. NAS 项目背景与职责
    1. NAS 项目是做什么的，你在里面负责什么。
    2. 智能文档和云端是否都是你负责的后端应用。
    3. NAS 项目做了多久，你是否参与技术选型。
    4. 产品是运行在别人的 NAS 里，还是软硬件一体的 NAS 设备。
    5. 当前系统是否使用 Docker，整个 NAS 里面是否是多个程序。
    6. NAS 跑在什么系统和芯片上，内存配置是多少。
    7. NAS 里是否打包 MySQL、Redis，为什么选择 SQLite 和 Ristretto。
3. 云端与 NAS 穿透
    1. NAS 是否会连接云平台，云端部分你负责什么。
    2. OTA 是否了解，A/B 分区是什么。
    3. 云端 NAS 有多少人做。
    4. NAS 穿透是怎么做的，信令服务、穿透端、邀请码、校验码分别承担什么角色。
    5. 是否使用开源框架或 SDK。
    6. 你怎么理解 NAS 穿透，它解决的核心问题是什么。
    7. NAS 穿透和 VPN、P2P 有什么区别。
    8. 设计 NAS 穿透时核心在哪里，如何处理身份校验、链路安全和对端发现。
    9. 做穿透方案时是否参考过开源项目，为什么选择邀请码机制。
4. 文档中心与搜索引擎
    1. 为什么从 ES 迁移到 Bleve。
    2. ES 在 NAS 资源受限场景下有什么问题。
    3. Bleve 的优势是什么，内存占用优势是什么。
    4. 你是怎么找到 Bleve 这个搜索引擎的。
    5. 整体环境、Bleve 和后端服务是怎么部署到 NAS 上的。
5. 文件索引同步系统
    1. 用 BFS 加队列架构替代 fsnotify 文件监听的前因后果是什么。
    2. fsnotify 在文件夹数量多、层级深、事件多时有什么问题。
    3. BFS 遍历加队列如何同步数据库索引和 NAS 真实文件。
    4. 当前队列用的是什么。
    5. 断点恢复指服务挂掉还是整体重启，如何通过任务状态机恢复 indexing、fail、pending 状态。
    6. 队列里的任务是否是同步任务，是否每个目录一个任务。
6. NAS 功能与性能排查
    1. 整个 NAS 除了文档、云端、穿透、相册和文件同步，还有哪些功能。
    2. 整个系统服务是否复杂，是否是单体服务。
    3. 是否了解 Go 的 GC 触发以及性能排查。
    4. 文档中心内存占用高时，你如何通过 top、pprof、Bleve 源码定位并优化。
    5. 文档解析工具选型时，为什么没有选择 Apache Tika、Pandoc、Python/PyTorch 相关方案。
    6. 是否考虑过用内存池降低内存占用。
7. Channel、Select 与 SQLite
    1. 项目里 select、channel 用得多不多。
    2. 模糊检测里如何使用多个并发任务和 Channel 收集结果。
    3. 你怎么理解 Channel 和 select，通常用在什么场景。
    4. 使用 Channel 时有没有遇到多读多写、死锁之类的问题。
    5. SQLite 写入频率多高，哪些数据会存在数据库里。
8. MQ 与队列选型
    1. 之前在哪里用过 MQ。
    2. 云端为什么用 MQ 记录事件和削峰。
    3. NSQ 是否是独立进程，是否支持持久化。
    4. 云端消息来源是什么，为什么会有较高 QPS。
    5. 为什么选择 NSQ，而不是 RabbitMQ、Kafka。
    6. 是否考虑过 RabbitMQ，为什么没有选择。
9. 协作、Docker 与其他项目
    1. 为什么会参与 Android 或其他端的协作。
    2. 为什么学习 Docker 和 K8s，NAS 里的 Docker 功能是什么。
    3. 毕业后是否一直在这家公司做 NAS，是否做过其他项目。
    4. 智能客服/智能邮件系统做什么，如何用 Milvus 和 AI 生成相似回复。
    5. 智能客服接入了哪些大模型，项目完成周期和参与人数是什么。
10. TCP 与 AI 开发
    1. TCP 了解多少，是否了解三次握手、四次挥手和可靠性。
    2. 目前 AI 用得多不多，如何进入编码流程。
    3. Codex 和 Cursor 分别怎么配合使用。
    4. AI 能帮你节省多少工作，它覆盖了哪些开发流程。
    5. 如何复测 AI 生成结果、code review 和测试用例。
    6. Cursor 和 Codex 的账号或套餐情况。

[同类追问预测]
这个面试官的风格是强项目真实性验证，会不断追问“你到底负责了什么、系统真实部署在哪里、为什么这么选型、有没有了解底层”。提问覆盖广，但重点不是背概念，而是让候选人把 NAS 的硬件环境、服务部署、云端穿透、搜索引擎、队列和 AI 项目都讲成一个能落地的工程系统。后续很可能继续沿着边界场景、资源约束、方案取舍和真实使用规模追问。

1. NAS 架构与部署
    1. NAS 固件里多个后端服务是如何启动、守护和重启的。
    2. 如果某个服务崩溃，系统如何拉起，日志如何采集。
    3. SQLite 数据库文件放在哪里，升级固件时如何保证数据不丢。
    4. Ristretto 缓存的 key、TTL、淘汰策略怎么设计。
    5. ARM 设备和普通云服务器在 CPU、内存、磁盘 IO 上的限制有什么不同。
    6. 如果 8GB 内存不够，系统会如何降级或限制任务并发。
2. NAS 穿透与网络
    1. STUN、TURN、信令服务分别解决什么问题。
    2. 如果 P2P 打洞失败，是否有中继兜底方案。
    3. 邀请码、穿透凭证、校验码分别如何生成、过期、撤销和防重放。
    4. 多个手机同时远程访问同一台 NAS 时，连接和权限如何管理。
    5. NAT 类型不同会如何影响穿透成功率。
    6. 穿透链路上的 AES、SHA 分别用于加密、签名还是完整性校验。
    7. 云端信令服务故障时，已经建立的连接和新连接分别会发生什么。
3. Bleve 与文档搜索
    1. Bleve 建索引时内存为什么会升高，哪些配置会影响峰值内存。
    2. 分块索引会不会影响搜索结果排序、召回率和高亮。
    3. 关闭 all page 或调整 store 后，索引体积和查询性能有什么变化。
    4. 1GB 文档内容占用 2GB 内存时，是否符合 NAS 资源预算。
    5. 如果索引构建中断，如何保证索引文件和数据库状态一致。
    6. 文档解析失败、乱码、超大文件、密码文件分别怎么处理。
4. 文件同步与队列
    1. fsnotify 漏事件后，如何证明 BFS 扫描能补齐所有变化。
    2. BFS 扫描全盘时如何控制 IO，避免影响用户正常访问。
    3. 每个目录一个任务时，目录层级很深会不会导致队列膨胀。
    4. indexing、fail、pending 状态如何流转，是否有最大重试次数。
    5. 断点恢复时如何避免重复处理同一个文件。
    6. 数据库索引和真实文件不一致时，以哪边为准。
5. Go 并发与内存优化
    1. Channel 在模糊检测里如何关闭，如何避免 Goroutine 泄漏。
    2. 多个结果 Channel 和错误 Channel 如何用 select 统一收敛。
    3. 如果某个图片处理卡住，如何通过 context 或 timeout 取消。
    4. sync.Pool 和普通缓存有什么区别，为什么内存池不是“把文件读进内存复用”。
    5. pprof 里如何区分内存泄漏、内存峰值和对象频繁分配。
    6. GC 频繁触发时，如何从 GODEBUG、pprof 和指标里定位原因。
6. SQLite、NSQ 与消息可靠性
    1. SQLite 在高写入并发下如何处理锁竞争，是否开启 WAL。
    2. SQLite 数据表如何设计索引，如何避免查询拖慢 NAS。
    3. NSQ 的 ack、requeue、timeout 机制是什么。
    4. NSQ 消息持久化在哪些情况下仍可能丢失。
    5. 事件记录需要幂等吗，重复消费会有什么影响。
    6. Kafka、RabbitMQ、NSQ 在部署复杂度、可靠性、吞吐和功能上怎么取舍。
7. Docker、K8s 与协作
    1. NAS Docker 功能是让用户运行容器，还是你们内部服务用容器部署。
    2. Docker 镜像在 NAS 上拉取、存储和升级时会遇到什么资源限制。
    3. K8s 你了解到什么程度，Deployment、Service、Ingress 分别解决什么问题。
    4. 你协助 Android 同事时，具体做了哪些功能和联调工作。
    5. 跨端联调出现协议不一致时，如何定位是前端、移动端、云端还是 NAS 的问题。
8. 智能客服与 AI 工程
    1. Milvus 里存的是什么 embedding，向量维度和相似度算法怎么选。
    2. 历史邮件如何清洗、切分、去重后再入库。
    3. 相似邮件召回后，如何让大模型生成回复而不是直接复制历史回复。
    4. DeepSeek 和秘塔模型在成本、效果、速度上有什么差异。
    5. AI 生成回复如何审核，如何避免泄露客户隐私或生成错误承诺。
    6. Codex 和 Cursor 在你的工作流里如何分工，什么任务更适合哪个工具。
9. TCP 与车联网反问延展
    1. TCP 三次握手、四次挥手的每一步状态是什么。
    2. TCP 如何保证可靠性，滑动窗口、重传、拥塞控制分别起什么作用。
    3. 如果面向车联网长连接，心跳、断线重连、消息确认如何设计。
    4. TCP 和 MQTT 在车联网场景下各有什么优缺点。
    5. 30 到 50 万车辆全部连接平台时，连接数、消息峰值和服务扩容怎么估算。
