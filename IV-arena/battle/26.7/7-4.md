1. 项目挑战与性能优化
    1. pprof 里 heap、alloc_space、inuse_space 分别适合看什么。
    2. 你如何判断文档中心是内存泄漏、内存峰值过高，还是 GC 压力过大。

2. Go Slice、Map 与逃逸
    1. Slice 扩容后原数组什么时候还会被引用，可能导致什么内存问题。
    2. Slice 作为函数参数传递时，修改元素和 append 分别会不会影响调用方。
    3. concurrent map read and map write 为什么是 fatal，而不是普通 panic。
    4. Map 遍历为什么设计成随机顺序，业务上如果需要稳定顺序怎么做。
    5. 值 receiver 和指针 receiver 对接口实现有什么影响。
    6. 用 `go build -gcflags=-m` 看到某个变量逃逸后，如何判断是否值得优化。
