1. Go GMP 调度
    1. 如果一个 Goroutine 长时间执行 CPU 密集任务，Go 调度器如何抢占它。
    2. P 的本地队列和全局队列分别在什么情况下使用，work stealing 为什么偷一半。
    3. netpoller 唤醒 Goroutine 后，G 会优先放回哪里，为什么不一定直接运行。
    4. 系统调用阻塞时，为什么要让 P 和 M 解绑，什么情况下会新建 M。
    5. GOMAXPROCS 设置过大或过小会带来什么影响。
2. Go 基础结构
    1. channel 无缓冲和有缓冲发送时，阻塞条件分别是什么。
    2. 关闭 channel 后继续发送、继续接收分别会发生什么。
    3. slice 扩容后原数组什么时候还会被引用，可能造成什么内存问题。
    4. map 扩容和迁移大致怎么做，为什么遍历 map 是无序的。
    5. sync.Map 适合什么读写场景，和 RWMutex 包 map 相比有什么取舍。
3. 逃逸分析与内存优化
    1. 你如何用 `go build -gcflags=-m` 判断某个变量是否逃逸。
    2. pprof 里 heap、alloc_space、inuse_space 分别看什么，定位内存峰值应该看哪个。
    3. Bleve 建索引时为什么会产生高内存占用，`StoreField` 改为 false 牺牲了什么能力。
    4. 分块处理和批量提交之间如何选择，块太大或太小分别有什么风险。
    5. 如果线上无法复现内存问题，你会如何采集证据和保护用户数据。
4. MySQL 查询优化
    1. N+1 查询在日志或慢 SQL 中怎么发现，如何量化优化效果。
    2. 使用 `IN (...)` 批量查询时，如果 ID 数量很多会有什么问题，如何分批。
    3. 为什么不用 left join，一次 join 和两步查询加内存聚合分别适合什么场景。
    4. 这个相册项目的表结构、索引设计、查询条件和排序规则是什么。
    5. MySQL 可重复读如何避免幻读，MVCC 和 next-key lock 各自起什么作用。
5. 缓存与简历真实性
