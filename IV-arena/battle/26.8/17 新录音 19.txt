## HTTPS、证书与 HTTP 版本

**问：** HTTP 和 HTTPS 有什么区别？TLS 的加密过程是什么？

**答：** HTTPS 是 HTTP 加 TLS，TLS 使用混合加密。A 和 B 通信，各自生成公私钥并交换公钥，通过私钥和公钥生成共享秘密，再生成密钥。发送请求时通过密钥加密，另一边通过相同密钥解密。

中间人可能截获公钥并发送自己的公钥，这时使用证书解决，发送信息、公钥和数字签名。B 端对信息做哈希得到哈希值，再使用私钥加密得到数字签名；A 端用公钥验证签名得到哈希值，并对信息和公钥做哈希，比较两个哈希值。[...2.4s]

**问：** 客户端怎么验证服务端证书是否可信？

**答：** [...0.8s] 它这边好像会预置一些信任的根证书吧。[...3.7s]

**问：** HTTP/1.0、1.1、2 和 3 有什么区别？

**答：** 1.0 和 1.1 的话，多了响应、更加精细的缓存策略、默认长连接，还支持断点续传。

HTTP/1.1 一条 TCP 上，如果 A 阻塞，B、C 也阻塞；HTTP/2 有多路复用，可以分帧，例如按 A1、B1、A2 交错发送，但是仍然是一条 TCP，一个包阻塞后其他流也会受影响。

HTTP/3 使用 QUIC，一条 Stream 上某个包阻塞，不会阻塞其他 Stream。[...2.7s]
